# DSGEA

This is the code for the paper:

**An Evolutionary Algorithm Based on Dynamic Sparse Grouping for Sparse Large Scale Multiobjective Optimization**\
Yingjie Zou, Yuan Liu, Juan Zou, Shengxiang Yang, Jinhua Zheng\
*Information Sciences*, vol. 631, pp. 449–467, 2023. [[Paper]](https://doi.org/10.1016/j.ins.2023.02.062)

## Requirements

The platform to run this code is [PlatEMO](https://github.com/BIMK/PlatEMO) 4.1 and above.
